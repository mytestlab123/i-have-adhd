# Amit's visual learning lab

Open **[amit-learning.html](./amit-learning.html)** as a rendered HTML file in a browser. GitHub's file view shows source code: use its **Download raw file** control, then open the downloaded file in Edge, Chrome, Firefox, or Safari. No build or package installation is required.

## Start with one action

Choose **Show me the rules** for one-card-at-a-time learning, **Before / after lab** for examples, or **My takeaway** for the proposed personal adaptation.

## Included

- Nine learning sections; all ten canonical rules and all six source exceptions.
- Ten before/after rule cards, five interactive practice scenarios, an interactive four-layer repository map, and five knowledge-check questions.
- Source-reported evaluation charts, the FAILED release gate, test-design limitations, and a proposed keep/adapt/defer playbook.
- Focus view, larger text, keyboard navigation, pause dialog, and optional browser-local progress.
- Short spoken section summaries when the browser exposes a local English voice. No autoplay; no remote voice is selected. Without a local voice, the page explains the limitation and remains usable visually.
- Pinned source links and the upstream MIT copyright/permission notice.

## Privacy and scope

The page is a self-contained learning artifact: no external scripts, fonts, images, analytics, model calls, or installation. External source links open GitHub only when selected. Clipboard writes require a button click. Local-storage persistence is opt-in and can be erased using Reset progress.

Source-derived content, illustrative examples, and proposed Amit adaptations are labeled separately. Reported repository evaluations were not reproduced here and are not clinical ADHD evidence. This artifact does not change the canonical skill, mirrors, hooks, manifests, or user configuration.
